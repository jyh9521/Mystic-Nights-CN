玻璃标题的 UV 是镜像加旋转的 `TRANSVERSE`，不是普通旋转。去字保留实际 6px 棋格周期，并按同相位源材质恢复；旁边不清楚的三行微字保持原像素，不编译文。原红门与嵌入红门的亮度归一化字区相关度为 0.995635；电脑变体为 0.957958，这些是关联依据而非像素相同的说法。每个变体仍独立绑定原 hash、CLUT、成员偏移和所有引用。

新增显式 `visual_families`，补足文件名闭包；组内存在未本地化来源时验证拒绝。当前为 **195 张本地化 TIM2／365 成员／512 个实装字段**，另有 1 张 RGB24 标题；187 张其他本地化 TIM2 不变。完整 delta、原生状态检查、HD 配方和新稳定编号反馈页同步更新。新增 68 块明确原材质保护样本，总共 264 块；MN alpha 与旧上沿内纹的 5 处历史样本期望调整逐项保留原因，没有删除原指纹。

## 生成素材和可复现性

使用内置 imagegen 提取已采用的完整透明难度/人名字稿，并生成无字监视器物理面；母稿已保存本地并经实际 alpha 检查。MN 生成稿改变几何、玻璃生成稿改变棋格相位，均弃用。提示摘要、采用/拒绝状态及输出 hash 记录在 `assets/artwork-authoring-review.json`；摘要不冒称原样工具调用记录。

普通构建只重放 `locales/zh-CN/artwork/` 的原生可逆差分及 `hd-artwork.json` 的自创 RLE，不依赖生成服务、系统字体或这些本地创作 PNG。基础工具不写入语言专有判断；本次坐标、颜色、全覆盖区和字形检查位于 locale 数据。CLUT16 只在显式 TEXA 配方下生成精确键，参见 [HD_PALETTE_PROFILES.md](HD_PALETTE_PROFILES.md)。
