# 《诡秘之夜》全文与图片测试

## 对象

`build/full-text/Mystic-Nights-zh-CN-full-text.iso`。以相邻 `manifest.json` 和 `VERIFICATION.txt` 的当前哈希为准，勿误用已否定的旧图片构建。

此版包含全部已提取正文、名称和联网设置，以及 7 张原风格图片重绘。其余图片稿待重绘，模糊字迹保持原图。PoC 菜单反馈不等于当前版验收。

游戏仅由玩家手动启动；工具不操作模拟器、BIOS、配置、记忆卡或存档。

## 图片检查

1. 标题菜单：检查《诡秘之夜》、4 个菜单项的普通/高亮状态、START 提示；不得有旧英文字影、色块底、错位或边框截断。
2. 难度与人物选择：检查蓝/橙两套状态，中文字重、金属高光、描边和底纹是否协调；原英文暗影不得残留。
3. 警告页：破损白字应直接落在原背景上，不出现黑条。
4. 道具菜单操作图：手柄连线、橙色“快捷语”、文字字号及底部跨两块的完整脚注连续。

## 正文和资源检查

- 从开场到结局检查对白推进、分支及中文字幕，不只测开场。
- 道具取得/消耗/合成、场景拾取和掉落：名称与说明一致，无查找失败。
- 文档在取得时和道具菜单重读；两处一致、分页正确。
- 检查系统/道具条件句号规则和原数值（恢复量、弹药等）。
- 使用独立测试存档槽记录保存和重载；旧存档兼容另记，不覆盖唯一存档。
- 网络设置检查中文、输入、提示、换行与网络配置记忆卡标题；服务器连通另作结果，不由显示通过推定。

## 反馈和恢复

反馈请带镜像哈希、位置、截图和是否能继续操作。没测的项目记“未测试”。恢复可直接选择保留原盘/PoC，或按 [BUILDING.md](../BUILDING.md) 在独立副本执行反向差分，不修改现有存档。
