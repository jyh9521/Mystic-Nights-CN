# 《诡秘之夜》首批全文汉化测试

## 测试对象

`build/partial/Mystic-Nights-zh-CN-partial.iso`，SHA-256：

`a40878eac2a5645b810d13ed69c8f8d8317ca8d3652f584765e120ced2907e95`

本批包含开场至二层EVENT 10..67、全部单机/联机道具说明及提示、首6份文档、13个系统槽。340个物理正文槽，646字形；后续剧情及道具名称仍有韩文。不是完整汉化版。

PoC收到“能显示确定和取消”的反馈，仅记为菜单中文显示通过。旧PoC保留为已反馈的对照；原盘不变。游戏/PCSX2由玩家手动启动，工具没有改动模拟器、BIOS、配置、记忆卡或存档。

## 本批检查顺序

1. 手动选择上面的新ISO，确认启动、读取资源正常。
2. 从开场检查独白及詹妮弗相遇：中文是否缺字/串位、越框，文本推进是否正常；留意`布鲁斯·麦凯伦`等姓名和省略号。
3. 二层调查与合成操作中核对门卡、供电、样本投入提示；名称暂为韩文，但说明与相应事件正文应出现中文。
4. 查看恢复药、弹匣、武器说明：比例仍为30%/60%/100%，弹药15/30/6发；无内部标点的系统提示/说明没有末尾句号。
5. 阅读管理指示、报纸残片、给沃尔特的便条、沃尔特手册、罗温·斯韦尔手册、反应结果打印件。分别在取得时和道具菜单重读，检查两条入口内容一致、12页的翻页/换行正常。
6. 如进行存读档验收，使用独立测试存档槽，并记录保存和重载结果。无需为本批先通关。

网络路径只进行了资源回填/离线验证，不应把菜单操作或离线说明显示推断为服务器连接正常。

## 回传信息

出现问题时提供ISO文件名、PCSX2版本、事件/道具/文档位置和截图，并说明是否测试过对白推进与存读档。没有测试的项目保持“未测试”。

## 恢复

重新选择原版ISO或保留的PoC即可。差分反向恢复见[BUILDING.md](../BUILDING.md)，会输出全新的原盘副本，不修改现有存档或模拟器设置。
