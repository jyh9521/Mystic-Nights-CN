# 《诡秘之夜》全文与图片测试

## 对象

`build/full-text/Mystic-Nights-zh-CN-full-text.iso`。以相邻 `manifest.json` 和 `VERIFICATION.txt` 的当前哈希为准，勿误用已否定的旧图片构建。

此版包含全部已提取正文、142 个房间显示名、名称和联网设置；全盘源图复核后，492 项可翻译图字写入 187 张 TIM2、343 个物理成员，另有 NETGUI 背景标题。2 项 D.I.A 及模糊字迹保持原图。旧菜单反馈不等于当前版验收。

请停止游戏后选择本次新 ISO 冷启动，不加载旧即时存档。相邻 manifest/VERIFICATION 的哈希是识别新版本的依据，不以窗口上旧文件名或缓存图像判断新图是否安装。

游戏仅由玩家手动启动；工具不操作模拟器、BIOS、配置、记忆卡或存档。

## 图片检查

1. 标题菜单：逐项切换新游戏、读取游戏、联机游戏、画廊（已解锁时），停稳后对比普通/高亮字高与字宽；高亮字不应明显变小，字下不得出现额外白横线。检查《诡秘之夜》、START 提示；不得有旧英文字影、色块底、错位或边框截断。胶囊本来的金属外框和工业底纹保留。
2. 难度与人物选择：检查蓝/橙两套状态，中文字重、金属高光、描边和底纹是否协调；原英文暗影不得残留。
3. 警告页：破损白字应直接落在原背景上，不出现黑条。
4. 道具菜单操作图：手柄连线、橙色“快捷语”、文字字号及底部跨两块的完整脚注连续。
5. 设置页：亮度、背景音乐、音效、振动和视角设置；开启／关闭与原复选框不重叠，滑杆与最小／最大值位置正确。
6. 载入与游戏结束：两种载入动画状态、继续提示、是／否两套状态；无旧字轮廓或被截断的字。
7. 联机界面：12 个青色标题、6 类操作文字、身份卡、随机选择、已选择印章；暗淡／模糊状态仍保留，不误当残留删除。检查原样保留的按键图标。
8. 公司呈献、结尾和职员表：角色名与配音演员对应，所有行完整；红色职位、白色姓名及两栏间距正确。
9. 场景标牌与终端：两种 G362 的“请勿靠近”后面没有逗号；旋转方向与贴图映射正确。检查出口、禁入、错误、访问被拒绝、培养箱和监控标签，无旧字残影、底色块或透明层缺笔。
10. 门卡和画廊：人物卡、通行证的名字／等级完整；画廊可读视图标签及斜排“诡秘之夜”没有覆盖原画或 MN 徽记。五张模糊手稿保持原状。
11. 网络设置背景：左侧淡黄标题为“诡秘之夜”；原背景与阴影自然连续，不与 PF 动态文字混淆。
12. 场景实际对照：“无信号 / 警报：紧急状态”、生命创造/出口玻璃门的各破损状态、易碎/食品/主系统、已锁定—密码及典型错误；同场景不同光照状态都检查，非只看一张预览。

## 正文和资源检查

- 从开场到结局检查对白推进、分支及中文字幕，不只测开场。
- 道具取得/消耗/合成、场景拾取和掉落：名称与说明一致，无查找失败。
- 文档在取得时和道具菜单重读；两处一致、分页正确。
- 检查系统/道具条件句号规则和原数值（恢复量、弹药等）。
- 检查 `（锁着）` 及其他括号单句不带多余句号；对白末句和文档长句自动折行后不把句号、逗号、右引号等单独放到下一行首。
- 检查原先乱码的房间标签是否对应纳米细胞实验室等中文名称，特别检查窄标签裁切和变更房间时的更新。
- 使用独立测试存档槽记录保存和重载；旧存档兼容另记，不覆盖唯一存档。
- 网络设置检查中文、输入、提示、换行与网络配置记忆卡标题；服务器连通另作结果，不由显示通过推定。

## 反馈和恢复

反馈请带镜像哈希、位置、截图和是否能继续操作。没测的项目记“未测试”。恢复可直接选择保留原盘，或按 [BUILDING.md](../BUILDING.md) 在独立副本执行反向差分，不修改现有存档。

## 宽屏与金手指（人工测试）

按 [RUNTIME_PATCHES.md](RUNTIME_PATCHES.md) 使用当前 CRC 对应文件，四项分别开启并冷启动。宽屏检查横向视野、人物比例、纵向内容、HUD 与过场；摇杆左右转向分别在普通/瞄准时测试，上下不应变化；各武器连续射击及装填检查弹匣/备用弹药；生命检查普通攻击、周期伤害及关闭开关冷启动后正常受伤。不要把未测试的武器、伤害或剧情路径填成通过。
