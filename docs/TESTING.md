# 《诡秘之夜》中文验证版测试

## 测试对象

`build/poc/Mystic-Nights-zh-CN-poc.iso` 是独立验证镜像。原盘保持不变。当前只检查中文显示链路，绝大多数内容仍保持韩文；主菜单图片也未改。

游戏和 PCSX2 由玩家自行启动。本轮没有自动启动模拟器，也没有修改 `pcsx2/`、记忆卡或存档。

## 检查步骤

1. 在现有 PCSX2 中手动选择测试 ISO 启动，确认没有黑屏、卡死或资源加载错误。
2. 出现保存选择时，应看到 `请选择保存数据的记忆卡插槽`；确认/是/否应显示中文。该句末尾没有句号。
3. 进入游戏后打开道具/暂停界面，查看 `武器、恢复药、道具、文档、选项、操作说明、设置` 是否缺字、挤压或串位。
4. 新游戏开场的首条被选中剧情文本（EVENT 10 / 第一个 TEXT）应显示 `这还是头一回。`，句号保留。确认文字完整、推进正常；是否出现/具体镜头以游戏实际流程为准。
5. 遇到相应开门/取得提示时，查看 `门已经打开`、`获得了…` 是否正常；只修改了一个已定位提示副本，其他场景的镜像提示仍可能显示韩文。
6. 如愿进行存读档检查，请使用单独测试存档槽，记录保存和重新读取后的表现。

## 回传内容

- 选中的 ISO 文件名与 PCSX2 版本。
- 中文提示、暂停/道具栏、首条对白的截图。
- 缺字、裁切、错位或异常停止的位置和触发方式。
- 保存/加载是否实际测试；未测试就注明未测试。

本轮至少需要确认字体、系统提示、对话推进正常，才能把同一技术链路扩展到成批译文。无需为了字体测试先完成通关。

## 恢复

重新选择原版 ISO 即可，原镜像从未被覆盖。也可按 [BUILDING.md](../BUILDING.md) 用差分反向生成逐字节相同的原盘副本。恢复镜像不修改游戏存档或模拟器配置。
