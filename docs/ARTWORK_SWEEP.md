## 可复现检查

```powershell
python -X utf8 tools/verify_artwork_review.py --original "[full2]미스틱 나이츠(K).iso" --iso build/full-text/Mystic-Nights-zh-CN-full-text.iso
python -X utf8 tools/verify_artwork_states.py --iso build/full-text/Mystic-Nights-zh-CN-full-text.iso --catalogue locales/zh-CN/graphics.json
```

`--material-only` 可对保留的旧版本复现暗纹检测红灯，不跳过源样本身份核对。检查覆盖 193 条逐图记录、361 物理成员及 64 个明确旧样本；尺寸、状态和透明边界仍走原有独立检查。空的 shape-pair 列表不构成居中或轮廓一致证明。
